# AgroFuturo Sustentável — Agrinho 2026

Site desenvolvido para o **Concurso Agrinho 2026**  
Tema: *Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente*

## Estrutura do projeto

```
agrinho-site/
├── index.html          # Estrutura HTML
├── style.css           # Estilos CSS
├── script.js           # JavaScript (interatividade)
├── assets1/
│   ├── paisagem1.png   # Imagem do hero
│   └── paisagem2.png   # Imagem da seção sustentabilidade
└── README.md
```

## Funcionalidades

- Menu responsivo (hambúrguer no mobile)
- Animações ao rolar a página (Intersection Observer)
- Slider interativo de economia de água
- Formulário de contato com validação
- Design responsivo (mobile, tablet e desktop)
- Tema alinhado ao Agrinho 2026

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Ou faça upload da pasta completa no GitHub Pages

## Tecnologias

- HTML5
- CSS3 (variáveis, Flexbox, Grid, Media Queries)
- JavaScript (ES6+)
- Font Awesome (ícones)
